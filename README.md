# Ajay's Portfolio

This is a React + Vite portfolio template generated manually to showcase sections like Home, About, Projects, Skills, and Contact. It includes some basic styles and animations using CSS and [Framer Motion](https://www.framer.com/motion/).

## Getting Started

This portfolio is now a fully static page that loads React, Framer Motion, and other libraries directly from CDNs. You don't need to install anything or run a development server; simply open `index.html` in your browser (double‑click the file or drag it into the window).

> If you want to use npm/Vite for development or building later, you can still install dependencies and run `npm start`, but it's not required to view the site.

2. **Run in development mode**

```bash
npm start
```

3. **Build for production**

```bash
npm run build
```

4. **Preview production build**

```bash
npm run preview
```

> Note: If commands fail due to PowerShell execution policy, try running from a regular Command Prompt or update execution policy (`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`).

## Customization

- Replace placeholder text with your own information.
- Add project images and links in `src/components/Projects.jsx`.
- Update `src/components/Contact.jsx` with your email and social links.
- Style further with CSS or install a CSS framework.

## Deploy

You can deploy this site using services like Vercel, Netlify, GitHub Pages, etc.
